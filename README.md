# タギロン

隠された5枚の数字タイル(色と数字)を、質問カードの答えだけで先に完全に言い当てた方が勝ち。運の要素がない、論理推理の対戦ゲームです。
コンピュータ(3段階)か、1台の端末を交代で使う人間相手かを選べます。

ルールは付属の説明書(2人用)に基づいています。

## 遊び方

`index.html` をブラウザで開くだけです(ビルド不要)。

```sh
npm test   # ロジックとAIのテスト (Node.js)
```

## ルール(2人用)

- タイルは0〜9が各2枚の計20枚。色は赤と青で、5だけは緑が2枚です。
- 各自5枚を取り、小さい順に左から並べて隠します。同じ数字なら赤が左です。
- 場には質問カードを常に6枚表向きで並べます。使うたびに山から1枚補充します。
- 手番では「場のカードを1枚選んで質問する」か「相手のタイル5枚を宣言する」のどちらかを行います。
- 宣言は並びまで完全に合っていれば正解です。外れても続行できますが、その手番は質問できません。どこが違うかは分かりません。
- 先攻が正解したときに限り、後攻にも1回だけ宣言のチャンスがあります。後攻も正解なら引き分けです。後攻が先に正解したら、その場で後攻の勝ちです。
- 質問カードを使い切っても決着しなければ引き分けです。

### 説明書にない取り決め

説明書は「カードを使い切っても正解が出なければ引き分け」としか書いていないため、次のように扱っています。

- 最後のカードが使われたら、双方が1回ずつ宣言します(質問はできません)。両者の宣言が済んでから結果を判定し、両者正解または両者不正解なら引き分けです。

## 質問カード(21枚)

説明書に全文がある質問は忠実に実装し、残りは説明書にないため補いました(アプリ内の「質問カード一覧」でも確認できます)。

| 種別 | 質問 |
|---|---|
| 説明書 | 5はどこ? / 1または2はどこ?(どちらかを選ぶ) / 連続で隣り合っている色はどこ? / 連番になっているタイルはどこ? |
| 補完 | 3または4はどこ? / 6または7はどこ? / 8または9はどこ? / 赤のタイルはどこ? / 青のタイルはどこ? / 同じ数字のタイルはどこ? |
| 補完 | 5枚の合計数は? / 小さい方から3枚の合計数は? / 大きい方から3枚の合計数は? / 中央の3枚の合計数は? |
| 補完 | 赤のタイルは何枚? / 青のタイルは何枚? / 奇数のタイルは何枚? / 偶数のタイルは何枚? / 4以下のタイルは何枚? |
| 補完 | 中央のタイルは5以上? 4以下? / 最大の数と最小の数の差は? |

21枚の全ての質問を使えば、どの手札も一意に特定できます(テストで確認済み)。

## 構成

- `src/logic.js` — タイル、手札、質問カード、ゲーム進行(UIから独立)
- `src/ai.js` — コンピュータ対戦のAI。公開情報だけから相手の手札の候補を絞り込む
  - やさしい: 質問をランダムに選ぶ
  - ふつう: 6割は候補を最も絞れる質問を選ぶ
  - つよい: 常に候補を最も絞れる質問を選び、絞れない場合は宣言に賭ける
- `src/ui.js`, `style.css`, `index.html` — 画面
- `test/test.js` — ロジックとAIのテスト
